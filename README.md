# スカイライン・テクノロジーズ 企業サイト

東京・天王洲のソフトウェア開発会社「スカイライン・テクノロジーズ」の企業サイトです。
HTML・CSS・JavaScript をすべて `index.html` 1 ファイルにまとめた静的サイトで、ビルドやサーバーは不要です。

## ページ構成

| セクション | 内容 |
| --- | --- |
| お知らせ | 採用・実績・会社に関する最新情報 |
| ヒーロー | キャッチコピーと、稼働中システムを建物の高さで表した「立面図」 |
| 事業内容 | 業務システム開発 / モバイル・タブレットアプリ / クラウド・データ基盤 / 運用・保守 |
| 稼働中の実績 | 6 件のシステム一覧(行にカーソルを合わせると対応する建物が強調表示) |
| 開発の進め方 | ヒアリングから本番稼働までの流れと期間の目安 |
| 会社概要 | 会社情報 |
| 採用情報 | 募集情報 |
| お問い合わせ | 問い合わせ窓口 |

## ファイル構成

```
company-site/
├── index.html   # サイト本体(HTML・CSS・JavaScript を含む)
└── README.md
```

## ブラウザで開く手順

### 方法 1: ファイルを直接開く

1. エクスプローラーで `company-site` フォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザ(Edge・Chrome など)でサイトが表示されます。

別のブラウザで開きたい場合は、`index.html` を右クリックして「プログラムから開く」でブラウザを選ぶか、ブラウザのウィンドウへファイルをドラッグ&ドロップしてください。

### 方法 2: コマンドから開く

PowerShell で `company-site` フォルダに移動し、次のコマンドを実行します。

```powershell
start index.html
```

### 補足

- フォントは Google Fonts から読み込んでいます。オフライン環境では代替フォントで表示されますが、ページ自体は問題なく閲覧できます。
- `index.html` を編集した後は、ブラウザを再読み込み(`F5`)すると変更が反映されます。
